Instructions and method notes
  1. Export the entries or results from TeamUnify. Unzip it if it arrives as a .zip.
  2. Open the file here with Choose .sd3 / .cl2 or drag it onto the box.
  3. Check Step 2: how many times are SCM, SCY, LCM, and any unusual times to fix in TeamUnify first.
  4. Pick the target course, then the method. The preview updates as you change options.
  5. Review the changes and any skipped lines, then Save converted file.
  6. For the coach, use Coach review: print it or save it as PDF, or download the CSV. It lists every entry with the original, relabeled and converted time and a box to tick.

Relabel only changes the course letter and nothing else. A short course time relabeled as long course is still a short course swim, usually faster than the swimmer would go in a 50 m pool. Use it only when the meet host accepts that, or when the course code itself was wrong.

Standard conversion uses the Swim England equivalent-time formula. It models the speed gained from each turn, with a separate turn factor for each stroke and distance, plus a yards-to-meters measure for SCY times. Results are rounded to the hundredth. Events without a published factor (25s, 100 IM) and yard seeds on 400/800 free are skipped and listed. Relays are converted leg by leg, assuming four equal splits.

Custom factor multiplies each time by the factor you enter for its source course, then adds the seconds-per-100 offset scaled to the distance. The defaults are common rules of thumb: +2% for SCM to LCM, ×1.11 for SCY to SCM.

Only the 8-character time fields and their course codes are rewritten. Every other byte, line length and line ending is kept, so the file stays valid SDIF.
