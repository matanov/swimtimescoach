Help & privacy

Best times from Hy-Tek meet results, in your browser.

Your data stays with you

  • Result files are read by this page, on this device. They are never uploaded, and the page is blocked from sending anything over the network.
  • No accounts, no cookies, no tracking. Nothing is stored in the browser: closing the tab or pressing Clear forgets everything.
  • A saved session is a file you download and keep. It contains swimmers' names and results, so share it only with people who should see them.

Getting started

  1. Get the meet results as .cl2 files (Hy-Tek's results export, usually from the meet host or results site). .sd3 files and .zip results archives work too.
  2. Click Add files or drop them on the page. Add more meets at any time; a file you've already added is skipped.
  3. If the files have results from several teams, pick yours. Only your team's swimmers and swims are shown; to switch, open the meet line above the table and tap Change team.
  4. Pick swimmers with Choose swimmers. Search by name or filter by team.

Reading the table

  • Each cell is the swimmer's best time. "3 swims" means there are more: click the time to see every swim in that event, with the best marked.
  • By course gives each course its own columns: short course yards, short course meters, long course meters.
  • By event (SC + LC) puts each event in one column, short course best over long course best. Letters show the course: Y yards, S short course meters, L long course meters. —SC or —LC means no swim in that course; a blank cell means no swims at all.
  • Yards and meters times are never compared, so each course keeps its own best. 500/1000/1650 yards free share a column with 400/800/1500 meters.
  • DQ, NS, SCR and DNF never count as a best time.
  • Tick EFSL quals to box times that meet the European Forces Swim League 2025–2028 championship standards: a solid box for Long Distance Champs, dashed for Short Distance Champs. Each swim is judged at the swimmer's latest age, so a time that met last year's standard counts only if it also meets this one. Equal to the standard counts. Short course and long course meters only.
  • Swimmers are matched across meets by name. If a name is spelled differently in two meets, they show as two people.

Saving and sharing

  • Save session downloads one .zip with every meet you've loaded, the swimmers you picked and the current view. Later, Open session (or drop the file on the page) picks up where you left off.
  • Print / Save PDF prints the table in landscape. Tick Include all swims in print to add every swim after the table.
  • Download CSV gives the best times and every swim, for spreadsheets.
  • Share as file makes one .html file with just the swimmers you picked, to send by WhatsApp or email. Whoever gets it taps it to see the table, with no website or upload. If their phone only shows a preview, they can open swimtimescoach.com, tap Open session and choose the file.

Free and open source

Swim Times Coach is free to use, copy, change and share under the MIT License. The code is on GitHub. It includes JSZip (MIT) and the Barlow fonts (SIL Open Font License).

Use it without the website

  • Download the app: one .html file with everything in it. Double-click it to open it in your browser; it works offline, with no install.
  • The downloaded copy doesn't update itself. Download it again now and then to get new features.
